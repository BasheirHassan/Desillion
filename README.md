## 📋 ما هو ديسيليون؟

برنامج مكتبي متكامل يدير أعمال منشأتك من البداية للنهاية: فواتير، مخزون، حسابات، تقارير وإغلاقات — بواجهة عربية كاملة من اليمين إلى اليسار، ودعم للفاتورة الإلكترونية السعودية (ZATCA).

## 🧩 الأقسام والمميزات

| القسم | المميزات |
|-------|----------|
| 🛒 **الفواتير** | فواتير مبيعات ومشتريات ومرتجعات، حركة مخزنية (إدخال، إخراج، مناقلة)، بضاعة أول المدة، عروض أسعار وطلبيات شراء — ولكل نوع لونه وصلاحياته الخاصة |
| 📄 **القيود المحاسبية** | قيود قبض ودفع ومركّبة وافتتاحية، مع أنواع قيود مرنة تُعرَّف حسب حاجة منشأتك، ودفعات الإيجار والضرائب |
| 🏦 **الحسابات** | شجرة حسابات واضحة، كشف حساب لأي عميل أو مورد، دفتر أستاذ، ميزان مراجعة، ومعالجة الأرصدة |
| 📦 **المنتجات والمخزون** | تنظيم المنتجات بمجموعات ووحدات وشجرة سهلة، تعديل الأسعار فردي أو جماعي، تسوية المخزون، وتقارير حركة أي منتج |
| ⚖️ **نقطة التعادل** | معرفة نقطة تغطية نفقاتك الشهرية بعرض سنوي واضح |
| 📊 **الرسوم البيانية** | رسوم توضح حركة المنتجات والفواتير والقيود لفهم أداء منشأتك بنظرة واحدة |
| 🔒 **الإغلاقات** | إغلاق يومي للمبيعات وصندوق النقدية لضبط الدورة المالية |
| 👥 **التعريفات** | فروع ومستودعات وعملات وطرق دفع وسائقون، ومندوبو مبيعات بنظام عمولات كامل |
| 🛠️ **الأدوات والإعدادات** | إدارة المستخدمين والأدوار والصلاحيات، سجل نشاط كامل، نسخ احتياطي، وتدوير السنة المالية |

## ⭐ مميزات تحبها

- 🖨️ **صمّم فواتيرك بنفسك**: مصمم طباعة بالسحب والإفلات مع معاينة مباشرة وباركود ورمز QR.
- 🇸🇦 **الفاتورة الإلكترونية ZATCA**: جاهزة لمتطلبات الفوترة السعودية.
- ⌨️ **اختصارات لوحة مفاتيح**: حفظ وطباعة وبحث وجديد بضغطة زر لتسريع عملك اليومي.
- 🪟 **عمل بعدة نوافذ**: افتح كل فاتورة أو قيد في نافذة مستقلة وأنجز أكثر بوقت واحد.
- 📊 **تصدير إلى Excel**: صدّر أي قائمة أو تقرير بضغطة واحدة، واستورد منتجاتك من Excel مباشرة.
- 🔢 **ترقيم تلقائي منظم**: أرقام متسلسلة للفواتير والقيود دون فواقد أو تكرار.
- 📅 **سنوات مالية مستقلة**: كل سنة مالية بقبيتها الخاصة مع نقل الأرصدة تلقائياً عند بدء سنة جديدة.
- 🌐 **ربط أكثر من جهاز**: تابع عمل منشأتك من أي جهاز عبر الاتصال بالخادم الرئيسي.
- 💾 **نسخ احتياطي**: احمِ بياناتك من الضياع بضغطة زر.
- 🔑 **ترخيص آمن**: حماية حقوق استخدام البرنامج.
- 🕵️ **سجل نشاط تفصيلي**: اعرف من أضاف أو عدّل أي فاتورة أو قيد ومتى، بكامل تفاصيلها.
- 🌙 **التقويم الهجري**: عرض التواريخ هجرياً أو ميلادياً كما تفضل.
- 🛡️ **تحكم دقيق بالصلاحيات**: حدد ماذا يرى ويفعل كل مستخدم، حتى على مستوى كل نوع فاتورة.
